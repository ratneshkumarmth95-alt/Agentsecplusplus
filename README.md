# AgentSec

## Intelligent Security Event Monitoring Framework

AgentSec is a C++17 based cybersecurity simulation project developed to
demonstrate Object-Oriented Programming principles through a practical
security monitoring system.

The framework receives security-related events, evaluates predefined
detection rules, selects an appropriate response, and records the outcome.
The project focuses on building a modular and extensible architecture
rather than interacting with real-world security infrastructure.

The primary objective of this project is to understand how autonomous
decision-making can be represented using classes, inheritance,
polymorphism, composition, and software design patterns.

---

## Objectives

- Simulate common cybersecurity incidents
- Analyze events using predefined rules
- Generate automatic responses
- Demonstrate OOP concepts through a real-world use case
- Create a foundation for future intelligent security systems

---

## Current Features

### Event Processing

Supported event categories:

- Login Failure
- Port Scan Detection
- Malware Alert
- File Tampering

### Automated Responses

The system can perform actions such as:

- Ignore Event
- Notify Administrator
- Block Suspicious IP
- Quarantine Device

### Decision Engine

A central decision engine evaluates incoming events and determines the
best response according to matching rules.

### Logging

All decisions generated by the framework are saved for later analysis.

---

## System Workflow

Security Event

↓

↓

## OOP Concepts Demonstrated

- Classes and Objects
- Inheritance

- Composition
- Dynamic Binding

---

## Design Patterns Used

### Factory Pattern

Event objects are created through a centralized EventFactory instead of
direct object instantiation.

### Strategy Pattern

Different decision-making behaviors can be introduced without modifying
the core engine.
